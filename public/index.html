Funcionamiento Dual: Local y Nube

Tu mantenedor puede funcionar mediante GitHub Actions en la nube o localmente mediante este panel.

Ejecución en Nube

GitHub Actions (Secret `SUPABASE_PROJECTS`)

Corre automáticamente en la nube de GitHub sin necesidad de tener tu PC encendida. Lee tus credenciales encriptadas desde Settings ➔ Secrets ➔ Actions.

Ejecución Local

Dashboard Local (`data/projects.json`)

Al ejecutar `npm start`, puedes agregar proyectos localmente y probar la conexión con pings manuales. Los datos se guardan solo en tu computadora.
