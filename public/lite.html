Configuración de SUPABASE_PROJECTS:

Si clonas este repositorio, configura esta variable en las Environment Variables de Vercel o en los Secrets de GitHub Actions con tu propio JSON:

SUPABASE_PROJECTS.json 
[
  {
    "name": "Mi Base Supabase",
    "url": "https://xyzxyzxyz.supabase.co",
    "key": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "target": "table",
    "customTable": "nombre_tabla"
  }
]
↔ Desliza horizontalmente JSON

💡 Importante: Define siempre "target": "table" y "customTable" para ejecutar consultas reales en PostgreSQL y reiniciar la inactividad de 7 días.
